# Roadmap

Hushmark is an early `0.1.x` project. The canonical roadmap is maintained in
[`hushmark/hushmark`](https://github.com/hushmark/hushmark/blob/main/ROADMAP.md).

For this source-only mirror, current priorities are:

1. keep extraction deterministic, allowlisted, and covered by no-leak tests;
2. keep standalone bootstrap and verification reproducible without model weights;
3. preserve public package provenance, SBOMs, signatures, and license metadata;
4. keep component documentation and published package examples synchronized;
5. propagate eligible security and compatibility fixes from the canonical repository promptly.

This roadmap communicates direction, not a delivery promise. It does not include committing model
weights, private evaluation corpora, customer data, or deployment secrets to the mirror.
