# Support

Hushmark Open Core is community-supported on a best-effort basis.

| Need                    | Where to go                                                                                                    |
| ----------------------- | -------------------------------------------------------------------------------------------------------------- |
| Reproducible mirror bug | [Bug report](https://github.com/lokomotifai/hushmark-open-core/issues/new?template=bug.yml)                    |
| Feature proposal        | [Canonical repository](https://github.com/lokomotifai/hushmark/issues/new?template=feature.yml)                |
| Documentation problem   | [Documentation issue](https://github.com/lokomotifai/hushmark-open-core/issues/new?template=documentation.yml) |
| Usage question          | [Question](https://github.com/lokomotifai/hushmark-open-core/issues/new?template=question.yml)                 |
| Security vulnerability  | Follow [SECURITY.md](SECURITY.md); do not open a public issue                                                  |

Search existing issues first and include the smallest safe, synthetic reproduction. Remove personal
data, credentials, customer payloads, private corpora, and model weights. There is no guaranteed
response time or production SLA in the community project.
