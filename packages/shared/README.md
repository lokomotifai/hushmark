# @hushmark/shared

Public Zod schemas, error shapes, and generated taxonomy types shared by Hushmark's open-core
TypeScript packages.

```bash
npm install @hushmark/shared
```

The package describes protocol types; it does not detect, mask, or anonymize personal data by
itself. Hushmark applies reversible masking as a technical security measure, not as a compliance
guarantee.
