# Support

Hushmark is community-supported on a best-effort basis.

| Need                   | Where to go                                                                                          |
| ---------------------- | ---------------------------------------------------------------------------------------------------- |
| Reproducible bug       | [Bug report](https://github.com/lokomotifai/hushmark/issues/new?template=bug.yml)                    |
| Feature proposal       | [Feature request](https://github.com/lokomotifai/hushmark/issues/new?template=feature.yml)           |
| Documentation problem  | [Documentation issue](https://github.com/lokomotifai/hushmark/issues/new?template=documentation.yml) |
| Usage question         | [Question](https://github.com/lokomotifai/hushmark/issues/new?template=question.yml)                 |
| Security vulnerability | Follow [SECURITY.md](SECURITY.md); do not open a public issue                                        |

Before filing, search existing issues and include the smallest reproducible example you can share
safely. Remove personal data, credentials, model artifacts, customer payloads, and non-public logs.

There is no guaranteed response time or production SLA in the community project. Paid support, if
offered separately, does not change public issue priority or governance rights.
