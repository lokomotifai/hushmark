# Maintainers

Hushmark currently uses a founder-led maintenance model.

| Maintainer  | GitHub                                       | Responsibilities                                                |
| ----------- | -------------------------------------------- | --------------------------------------------------------------- |
| Fatih Guner | [@fatihguner](https://github.com/fatihguner) | Project direction, reviews, releases, and security coordination |

Maintainer status reflects active responsibility, not ownership of contributors’ copyrights. New
maintainers may be added after sustained, constructive contributions and demonstrated judgment in
the relevant area. Changes are recorded through a pull request to this file.

The project intentionally does not list inactive or fictional committees. If maintenance capacity
changes, [GOVERNANCE.md](GOVERNANCE.md) describes the transition process.
